# 06. 로컬은 통과하는데 CI에서만 테스트 7개가 실패

- **발생**: 2026-09-06
- **증상 한 줄**: 새로 추가한 마이그레이션 테스트가 CI에서만 DB 접속에 실패한다

---

## 현상

로컬에서는 45개 전부 통과했다.

```
45 passed, 1 warning in 1.22s
```

같은 커밋을 올렸더니 GitHub Actions에서는 38개만 통과하고 **7개가 오류**로 끝났다.
7개는 전부 새로 추가한 `test_migration_from_legacy.py`의 테스트였다.

## 환경

- 로컬: 임베디드 PostgreSQL (검증용으로 띄운 것, **비밀번호 없음**)
- CI: `postgres:15` 서비스 컨테이너, 비밀번호 `testpassword`

## 진단

### 1) 실패한 테스트가 하는 일

이 테스트는 예전 스키마를 만들 **별도 DB**가 필요해서, 테스트 DB 주소에서 이름만 바꿔 새 DB를 만든다.

```python
url = make_url(str(test_engine.url))
legacy_url = url.set(database=f"{url.database}_legacy")
```

### 2) `str(URL)`이 무엇을 돌려주는가

```python
>>> str(engine.url)
'postgresql://gymadmin:***@localhost:5432/gymdb_test'
>>> make_url(str(engine.url)).password
'***'
>>> engine.url.password
'testpassword'
```

**SQLAlchemy는 URL을 문자열로 만들 때 비밀번호를 `***`로 가린다.** 로그에 실수로 찍히는 걸 막기 위한 동작이다.

그 문자열을 다시 `make_url()`로 파싱하면, 비밀번호가 **`***`인 접속 정보**가 된다.
그래서 DB 연결이 인증에서 막혔다.

### 3) 로컬에서 왜 안 보였나

검증에 쓴 임베디드 PostgreSQL은 **비밀번호가 없었다.**

```
postgresql://postgres:@/gymdb_test?host=/tmp/...
```

가릴 비밀번호가 없으니 마스킹도 일어나지 않았고, 마스킹된 값으로도 접속이 됐다.
**비밀번호가 있는 환경에서만 드러나는 버그**였다.

## 원인

`str(URL)`의 마스킹된 결과를 다시 파싱해서 접속 정보로 썼다.

## 해결

URL 객체를 그대로 쓴다. `URL.set()`은 객체를 반환하므로 문자열로 만들 필요가 없다.

```python
# str(URL) 은 비밀번호를 '***' 로 가린다. 그 문자열로 URL 을 다시 만들면
# 비밀번호가 '***' 인 접속 정보가 되어 연결에 실패하므로, URL 객체를 그대로 쓴다.
url = test_engine.url
legacy_url = url.set(database=f"{url.database}_legacy")
```

다른 곳에도 같은 패턴이 있는지 확인했다.

```bash
$ grep -rn "str(.*\.url)\|make_url" api/ --include="*.py"
다른 URL 문자열화 없음
```

커밋 `59038f0`. 이후 CD 실행에서 테스트 잡이 통과했다.

```
API Test / pytest (FastAPI + PostgreSQL)   success
  ✓ Run tests                              success
```

## 재발 방지

- 접속 정보를 다룰 때 **문자열을 거치지 않는다.** `URL` 객체에는 `.set()`, `.render_as_string(hide_password=False)`처럼 의도를 드러내는 API가 있다.
- 로컬 검증 환경을 CI와 **같은 조건**으로 맞춘다. 특히 인증처럼 "있으면 다르게 동작하는" 부분.

## 배운 점

**보안을 위한 기본 동작이 버그를 만들 수 있다.** 마스킹은 옳은 기본값이지만,
그 결과를 다시 입력으로 쓰면 조용히 잘못된 값이 된다. 예외도 경고도 없다.

**"로컬에서 통과"는 환경이 같을 때만 의미가 있다.**
비밀번호 하나 차이로 7개가 갈렸고, 로컬만 봤다면 계속 못 찾았을 것이다.
