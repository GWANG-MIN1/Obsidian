## 3단계 · 2026-07-19 ~ 07-20 — 첫 라이브 (커밋 12개)

07-19 에 README 에서 진행 상태 절을 걷어내고, 07-20 에 처음으로 실제 계정에 올렸다.

```
20:36  Phase 1 검증 완료 — 노드 2개 Ready (v1.30.14-eks), 서브넷 2a/2c, state S3, OIDC
       ── (커밋 없음) hook Job 2개 Pending → 노드 3대로 (AWS CLI)      ← 트러블 01
21:04  fix: Loki 에 쓰기 가능한 /var/loki (emptyDir)                  ← 트러블 02
21:31  fix: CRD selectableFields 를 ignoreDifferences                  ← 트러블 03
21:35  fix: kyverno CRD 의 빈 맵 metadata 도 무시                      ← 트러블 03
21:41  Phase 2 검증 완료 — 8/8 Synced/Healthy
21:45  test: sample-app replicas 2 → 3   (push→sync 데모)
21:48  test: 3 → 2 되돌리기
21:54  검증 기록 · 트러블슈팅 01~03 · 로드맵 정리
21:56  스크린샷 2장
```

**push→sync 루프는 계획된 데모(21:45)보다 실전(21:04)에서 먼저 증명됐다.** Loki CrashLoop 을
values 수정 → push 만으로 고친 것이다. 저장소 기록도 *"계획된 데모보다 강력한 실전 증명"* 이라고 적었다.

그런데 같은 날의 첫 문제(트러블 01)는 **Git 이 아니라 AWS CLI 로** 고쳤다. 그래서 이날 이후
실제로 돈 클러스터(3대)와 Git 의 기본값(2대)이 달라진다.
