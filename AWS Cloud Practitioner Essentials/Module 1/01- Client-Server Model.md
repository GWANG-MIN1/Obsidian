클라이언트(고객)이 서버(바리스타)에게 주문을 하고 또 바리스타가 주문을 받는 것처럼 컴퓨팅 자원을 요청하면 그에따라 응답하여 필요한 자원을 할당 => 클라우드 컴퓨팅

즉, 종량제 요금으로 인터넷을 통해 IT 리소스를 온디멘드로 제공하는것 
종량제 요금 => 사용량 기반 요금
온디맨드 => 고객 필요에 따라 컴퓨팅 리소스에 액세스 

클라우드 배포 유형
1. 클라우드 기반 배포 : 외부 클라우드 서버 빌려 운영
2. 온프레미스 배포 : 회사 내부 서버 직접 운영
3. 하이브리드 배포 : 클라우드와 내부 서버 함께 운영
