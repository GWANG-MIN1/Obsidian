# AWS 연결 방식 비교

## VPN (Virtual Private Network)

### 특징

- 보안(Secure Connection)
- 유연한 연결
- 원격 액세스 지원
- 소규모 환경에 적합
- 전용 회선 없이 인터넷을 통해 연결

### 장점

- 구축 비용이 저렴
- 빠르게 구축 가능
- 재택근무, 원격 근무에 적합

### 한 줄 요약

> **인터넷을 이용한 안전한 가상 네트워크 연결**

# AWS Direct Connect

### 특징

- 높은 대역폭
- 낮은 지연 시간(Low Latency)
- 안정적이고 일관된 성능
- 대용량 데이터 전송에 적합
- 중요(미션 크리티컬) 애플리케이션에 적합

### 장점

- 인터넷을 거치지 않는 전용 회선
- 안정적인 네트워크 품질
- 대규모 트래픽 처리에 유리

### 한 줄 요약

> **전용 회선을 이용한 고성능 네트워크 연결**

# VPN vs Direct Connect
| 구분     | VPN        | AWS Direct Connect  |
| ------ | ---------- | ------------------- |
| 연결 방식  | 인터넷        | 전용 회선               |
| 비용     | 저렴         | 비교적 높음              |
| 대역폭    | 보통         | 매우 높음               |
| 지연 시간  | 상대적으로 높음   | 매우 낮음               |
| 성능     | 인터넷 품질에 영향 | 안정적이고 일정            |
| 적합한 환경 | 소규모, 원격 접속 | 기업, 대용량 데이터, 핵심 서비스 |
# 함께 사용하는 경우

VPN과 Direct Connect를 함께 구성하면 **고가용성(High Availability)** 과 **내결함성(Fault Tolerance)** 을 높일 수 있다.

### 일반적인 구성
```
On-Premises
      │
 ┌────┴────┐
 │         │
VPN   Direct Connect
 │         │
 └────┬────┘
      │
     AWS
```
### 역할

- **Direct Connect**
    - 기본(Primary) 연결
    - 높은 성능과 안정적인 통신 제공
- **VPN**
    - 백업(Backup) 연결
    - Direct Connect 장애 발생 시 자동으로 전환(Failover)

# 함께 사용하는 이유

- **장애 조치(Failover)** 지원
- **내결함성(Fault Tolerance)** 향상
- **고가용성(High Availability)** 확보
- 필요 시 **대역폭 확장** 가능
