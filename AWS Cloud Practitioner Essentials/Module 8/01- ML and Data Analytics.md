# 01. AI와 Machine Learning(ML)

## AI가 중요한 이유
- 고객의 정보와 데이터를 분석하여 **고객이 원하는 것을 더 정확하게 예측**할 수 있다.
- 기업은 AI를 활용해 고객 경험을 개선하고 새로운 서비스를 만들 수 있다.

---

# 인공지능(AI)

> **Artificial Intelligence (AI)**

인공지능(AI)은 **인간과 유사한 작업(Task)을 수행할 수 있는 지능형 컴퓨터 시스템을 개발하는 광범위한 분야**이다.

### AI 활용 예시
- 음성 인식
- 이미지 인식
- 자연어 처리(NLP)
- 추천 시스템
- 챗봇

---

# 기계학습(ML)

> **Machine Learning (ML)**

기계학습은 **명시적으로 모든 규칙을 프로그래밍하지 않아도 데이터를 학습하여 작업을 수행하는 AI의 한 분야**이다.

### 핵심 특징
- 데이터를 통해 스스로 패턴을 학습
- 새로운 데이터가 들어와도 학습한 패턴을 기반으로 예측
- 데이터가 많을수록 일반적으로 성능 향상

---

# 기존 프로그래밍 vs Machine Learning

## 기존 프로그래밍(Rule-Based)

개발자가 규칙을 직접 작성한다.

예시)

```
IF 고객이 제품 X 구매
THEN 제품 Y 추천
```

- 사람이 모든 규칙을 정의
- 새로운 상황이 생기면 규칙을 추가해야 함
- 복잡한 패턴을 찾기 어려움

---

## Machine Learning

방대한 고객 데이터를 학습하여 스스로 패턴을 찾는다.

과정

```
고객 데이터 수집
        ↓
데이터 학습
        ↓
ML 모델 생성
        ↓
새로운 고객 데이터 입력
        ↓
개인화된 추천 제공
```

예시

온라인 커피 주문 앱

- 고객 주문 기록 학습
- 비슷한 고객들의 주문 패턴 분석
- 새로운 고객에게 가장 어울리는 음식 추천

결과

- 개인 취향에 맞는 추천
- 기존 규칙보다 더 관련성 높은 추천 가능

---

# AI 활용 사례

## 1. 음식 추천 시스템

온라인 커피 주문 앱에서

- 고객 주문 기록 분석
- 구매 패턴 학습
- 개인 맞춤 메뉴 추천

예시

```
☕ 아메리카노 주문

↓

AI 추천

- 크루아상
- 치즈케이크
- 쿠키
```

---

## 2. AI 기반 키오스크

AI는 단순히 정해진 규칙만 따르는 것이 아니라 고객과 대화할 수 있다.

### 기능

- 음성 주문 인식
- 고객 질문 이해
- 주문 자동 처리

예시

고객

> 아이스 아메리카노 한 잔 주세요.

AI

> 샷을 추가하시겠습니까?

고객

> 네, 한 샷 추가해주세요.

↓

주문 자동 처리

---

## 자연어 처리(NLP)

AI 키오스크는 **NLP(Natural Language Processing)** 를 사용하여 사람의 언어를 이해한다.

가능한 기능

- 음성 인식
- 질문 이해
- 대화
- 주문 처리

---

## 3. 새로운 레시피 개발

AI는 바리스타가 새로운 메뉴를 만드는 데에도 활용될 수 있다.

예시

- 인기 메뉴 분석
- 고객 선호도 분석
- 새로운 음료 조합 추천
- 계절 메뉴 제안

---

# AWS와 AI

AWS는 AI/ML 개발을 위한 다양한 서비스를 제공한다.

지원 기능

- 데이터 저장
- 데이터 분석
- 모델 학습(Training)
- 모델 배포(Deployment)
- AI 서비스 활용

또한 일반적인 작업(Task)은 AWS의 **상용 AI 서비스(Managed AI Services)** 를 활용하여 별도의 모델 개발 없이 구현할 수도 있다.

---

# AI의 핵심은 데이터

AI 모델은 **다양한 장소에서 수집된 데이터**를 기반으로 학습한다.

### 데이터 처리 과정

```
데이터 수집
      ↓
데이터 정리
      ↓
데이터 전처리
      ↓
올바른 형식으로 변환
      ↓
모델 학습
      ↓
예측
```

---

# 데이터 품질의 중요성

AI 성능은 데이터 품질에 크게 영향을 받는다.

좋은 AI를 만들기 위해서는

- 정확한 데이터
- 충분한 데이터
- 깨끗한 데이터
- 일관된 데이터
- 올바른 전처리 과정

이 필요하다.

> **Garbage In, Garbage Out (GIGO)**
>
> 잘못된 데이터를 입력하면 잘못된 결과가 나온다.

따라서 **올바른 데이터와 적절한 데이터 처리 과정이 없다면 높은 예측 성능을 기대하기 어렵다.**

---

# 핵심 정리

- **AI**: 인간처럼 지능적인 작업을 수행하는 광범위한 기술
- **ML**: 데이터를 학습하여 스스로 예측하는 AI의 한 분야
- 기존 프로그래밍은 사람이 규칙을 작성하지만, ML은 데이터에서 패턴을 학습한다.
- AI는 추천 시스템, 음성 키오스크, 챗봇, 레시피 개발 등 다양한 분야에 활용된다.
- AWS는 AI 모델의 학습과 배포를 위한 다양한 서비스를 제공한다.
- AI의 성능은 **데이터의 품질과 전처리 과정**에 크게 좌우된다.
