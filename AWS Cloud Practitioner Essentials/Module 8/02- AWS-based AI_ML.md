# 02. AI/ML 활용 분야 및 AWS AI 서비스

## AI와 ML의 활용

오늘날 다양한 기업은 **인공지능(AI)** 과 **기계학습(ML)** 을 활용하여 비즈니스 문제를 해결하고 있다.

특히 ML 모델은 전자상거래의 추천 시스템뿐만 아니라 다양한 분야에서 활용된다.

### 활용 사례

- 📈 향후 주가 예측
- ☎️ 고객 전화를 적절한 부서로 자동 라우팅
- 💳 온라인 뱅킹의 금융 이상 거래(Fraud) 탐지
- 🛒 개인 맞춤형 상품 추천
- 📧 이메일 스팸 분류
- 🏥 질병 진단 및 의료 영상 분석

---

# AWS의 AI/ML 서비스

AWS는 AI와 ML을 활용할 수 있도록 크게 세 가지 방식의 서비스를 제공한다.

```
AWS AI/ML 서비스

├── AI 서비스
├── ML 서비스
└── ML 프레임워크 및 인프라
```

---

# 1. AI 서비스 (AI Services)

> 특정 기능을 수행할 수 있도록 **이미 학습(Pre-trained)** 된 모델을 제공하는 관리형 서비스

개발자는 모델을 직접 학습시키지 않아도 API를 호출하여 AI 기능을 사용할 수 있다.

### 특징

- 사전 구축(Pre-trained) 모델 제공
- 완전 관리형 서비스(Managed Service)
- 별도의 ML 지식이 적어도 사용 가능
- API 호출만으로 AI 기능 활용

### 대표 서비스

- **Amazon Polly**
  - 텍스트를 자연스러운 음성으로 변환(Text-to-Speech)

- **Amazon Comprehend**
  - 자연어 처리(NLP)
  - 문서 분석
  - 감정 분석
  - 키워드 추출

---

# 2. ML 서비스 (Machine Learning Services)

> 직접 ML 모델을 구축, 학습, 배포할 수 있도록 지원하는 관리형 서비스

대표적으로 **Amazon SageMaker AI**가 제공된다.

### Amazon SageMaker AI

완전 관리형 머신러닝 플랫폼으로,

- 모델 구축(Build)
- 모델 학습(Train)
- 모델 배포(Deploy)

과정을 하나의 환경에서 수행할 수 있다.

### 주요 기능

- 데이터 준비
- 데이터 시각화
- 모델 학습
- 하이퍼파라미터 튜닝
- 디버깅(Debugging)
- 모델 모니터링(Monitoring)
- 모델 배포

---

# 3. ML 프레임워크 및 인프라

> ML 환경을 직접 구성하여 **완전히 사용자 지정(Custom)** 방식으로 모델을 개발하는 방법

AWS는 원하는 프레임워크와 인프라를 자유롭게 사용할 수 있도록 지원한다.

### 특징

- 높은 자유도
- 원하는 프레임워크 선택 가능
- 원하는 라이브러리 설치 가능
- 원하는 환경 직접 구성

### 예시

ML에 최적화된 Amazon EC2 인스턴스를 생성하여

- TensorFlow
- PyTorch
- Jupyter Notebook

등을 직접 설치하고 사용할 수 있다.

---

# AI 서비스 vs ML 서비스 vs ML 인프라

| 구분 | AI 서비스 | ML 서비스 | ML 프레임워크 및 인프라 |
|------|-----------|------------|---------------------------|
| 모델 학습 | ❌ 필요 없음 | ✅ 가능 | ✅ 직접 수행 |
| 사용 난이도 | 가장 쉬움 | 중간 | 가장 어려움 |
| 자유도 | 낮음 | 높음 | 매우 높음 |
| 대표 서비스 | Amazon Polly, Amazon Comprehend | Amazon SageMaker AI | EC2 + TensorFlow, PyTorch |
| 사용 대상 | AI 기능만 사용 | ML 모델 개발 | 완전한 사용자 정의 ML 개발 |

# 핵심 정리

- 다양한 기업은 AI와 ML을 활용하여 여러 비즈니스 문제를 해결한다.
- ML은 추천 시스템뿐 아니라 **주가 예측, 고객센터 자동 라우팅, 금융 이상 거래 탐지** 등 다양한 분야에 활용된다.
- **AI 서비스**는 이미 학습된 모델을 API 형태로 제공하는 관리형 서비스이다.
- **ML 서비스(Amazon SageMaker AI)** 는 모델의 구축, 학습, 배포를 지원하는 완전 관리형 플랫폼이다.
- **ML 프레임워크 및 인프라**는 Amazon EC2 등에서 원하는 프레임워크를 직접 설치하여 자유롭게 ML 환경을 구축하는 방식이다.
