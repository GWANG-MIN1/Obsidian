# Amazon Relational Database Service (Amazon RDS)

## 관계형 데이터베이스(RDBMS, Relational Database Management System)

- 데이터를 **테이블(Table)** 형태로 저장
- **다른 데이터와의 관계(Relation)** 를 형성하여 데이터를 관리
- SQL(Structured Query Language)을 사용하여 데이터를 조회 및 관리

### 대표적인 관계형 데이터베이스 엔진
- MySQL
- PostgreSQL
- Microsoft SQL Server
- MariaDB
- Oracle Database

---

# Amazon RDS (Relational Database Service)

AWS에서 제공하는 **관리형(Managed) 관계형 데이터베이스 서비스**

데이터베이스 운영에 필요한 반복적인 작업을 AWS가 대신 수행하여, 개발자는 애플리케이션 개발과 비즈니스 로직에 집중할 수 있다.

## 주요 특징

- 자동 백업(Automatic Backup)
- 자동 패치(Automatic Patching)
- 하드웨어 프로비저닝
- 장애 감지 및 장애 조치(Failover)
- Multi-AZ를 통한 고가용성
- 재해 복구(Disaster Recovery)
- 성능 모니터링 및 최적화
- 비용 최적화

> 즉, 데이터베이스 유지보수보다 서비스 개발에 집중할 수 있다.

# Amazon RDS에서 지원하는 DB 엔진

- MySQL

# Amazon RDS의 장점

- 데이터베이스 관리 부담 감소
- 자동 백업 및 복원
- 자동 보안 패치
- 높은 가용성(Multi-AZ)
- 읽기 전용 복제본(Read Replica) 지원
- 손쉬운 확장(Scale Up)
- AWS 서비스와 높은 연동성

---

# AWS DMS (Database Migration Service)

기존 데이터베이스를 AWS 환경으로 이전(Migration)할 때 사용하는 서비스

## 특징

- 기존 데이터베이스를 Amazon RDS 또는 Aurora로 이전 가능
- 서비스 중단(Downtime)을 최소화하면서 데이터 이전 가능
- 서로 다른 데이터베이스 엔진 간 마이그레이션도 지원

예시

```
On-Premise Database
        │
        ▼
    AWS DMS
        │
        ▼
 Amazon RDS / Aurora
```

# AWS 공동 책임 모델 (Shared Responsibility Model)

## AWS의 책임

AWS는 클라우드 인프라를 관리한다.

- 물리적 서버
- 네트워크
- 스토리지
- 운영체제(OS)
- DB 패치
- 자동 백업
- 기본 인프라 유지관리

---

## 사용자의 책임

사용자는 데이터와 접근 권한을 관리한다.

- IAM 권한 관리
- 계정 및 사용자 보안
- 데이터 암호화 설정
- 전송 중 암호화(SSL/TLS)
- DB 접근 제어
- 애플리케이션 보안

---

# Amazon Aurora

AWS가 개발한 **고성능 관리형 관계형 데이터베이스**

MySQL 및 PostgreSQL과 호환되며, Amazon RDS보다 더 높은 성능과 가용성을 제공한다.

## 특징

- MySQL 호환
- PostgreSQL 호환
- Aurora DSQL 지원
- 불필요한 I/O 작업을 줄이도록 설계
- 높은 성능과 확장성
- 완전 관리형 서비스

---

# Aurora의 장점

## 뛰어난 성능

- 일반 MySQL보다 높은 성능
- 불필요한 I/O 감소
- SSD 기반 분산 스토리지 사용

---

## 높은 가용성

- 여러 가용 영역(AZ)에 데이터 복제
- Aurora Replica 최대 **15개** 생성 가능
- 자동 장애 조치(Failover)

---

## 자동 스토리지 관리

- 스토리지 자동 확장
- 자동 백업
- 스냅샷 관리

---

## 데이터 보호

- 저장 데이터 암호화(Encryption at Rest)
- 전송 데이터 암호화(In Transit)
- 지속적인 모니터링
- AWS Backup 지원

---

# Amazon RDS vs Amazon Aurora

| 구분 | Amazon RDS | Amazon Aurora |
|------|------------|----------------|
| 서비스 | 관리형 관계형 DB | AWS가 개발한 고성능 관리형 관계형 DB |
| 호환 엔진 | MySQL, PostgreSQL, MariaDB, Oracle, SQL Server | MySQL, PostgreSQL |
| 성능 | 일반적인 성능 | RDS보다 더 높은 성능 |
| 가용성 | Multi-AZ | 기본적으로 여러 AZ에 분산 저장 |
| 읽기 복제본 | 지원 | 최대 15개 Aurora Replica |
| 자동 백업 | O | O |
| 자동 패치 | O | O |
| 스토리지 | 사용자가 설정 | 자동 확장 |

---

# 핵심 정리

- **RDS** = AWS의 **관리형 관계형 데이터베이스 서비스**
- **Aurora** = AWS가 개발한 **고성능 RDS**
- **AWS DMS** = 데이터베이스 이전(Migration) 서비스
- RDS는 백업, 패치, 장애 조치 등을 AWS가 관리한다.
- 사용자는 IAM, 암호화, 접근 제어 등 보안 설정을 관리한다.
- Aurora는 높은 성능, 자동 스토리지 확장, 최대 15개의 복제본을 제공한다.
