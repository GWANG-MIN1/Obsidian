# EC2 구매 옵션 (Pricing Options)

EC2는 사용 목적과 워크로드 특성에 따라 여러 가지 구매 옵션을 제공한다.

---

## 1. 온디맨드 인스턴스 (On-Demand)

- 사용한 만큼 비용을 지불하는 방식
- 약정 없이 즉시 사용 가능
- 운영체제와 인스턴스 사용 시간에 따라 요금 부과

**적합한 경우**

- 테스트 및 개발 환경
- 단기 프로젝트
- 사용량 예측이 어려운 서비스

**활용 방법**

1. 서버를 가동
2. 테스트 및 워크로드 수행
3. 평균 사용량 분석
4. 이후 더 저렴한 구매 옵션 검토

---

## 2. 절감형 플랜 (Savings Plans)

- 일정 기간(1년 또는 3년) 사용량을 약정
- 온디맨드보다 저렴한 요금 제공

**특징**

- 지속적이고 일정한 사용량에 적합
- EC2뿐 아니라 서버리스 서비스에도 적용 가능

**적합한 경우**

- 장기간 운영되는 서비스
- 꾸준한 트래픽이 발생하는 시스템

---

## 3. 예약 인스턴스 (Reserved Instances)

- 특정 인스턴스를 장기간 예약하여 할인받는 방식
- 예측 가능한 워크로드에 적합

**결제 방식**

- 전액 선결제
- 부분 선결제
- 월별 결제

**적합한 경우**

- 데이터베이스 서버
- 24시간 운영되는 웹 서버
- 장기간 사용이 확실한 시스템

---

## 4. 스팟 인스턴스 (Spot Instances)

- 남는 AWS 자원을 매우 저렴하게 제공
- 온디맨드 대비 최대 약 90% 저렴

**단점**

- AWS가 필요할 경우 언제든지 인스턴스를 회수할 수 있음
- 작업이 중단될 수 있음

**적합한 경우**

- 배치 작업
- 데이터 분석
- 머신러닝 학습
- 중단이 허용되는 워크로드

---

## 5. 전용 호스트 (Dedicated Hosts)

- 물리 서버 전체를 한 고객이 독점 사용
- 다른 고객과 하드웨어를 공유하지 않음

**특징**

- 서버 배치와 자원 할당을 완전히 제어 가능
- 보안 및 규제 요구사항 충족 가능

**적합한 경우**

- 금융 및 의료 시스템
- 라이선스 제약이 있는 소프트웨어
- 높은 보안이 필요한 환경

---

# 구매 옵션 비교

|구매 옵션|비용|중단 가능성|적합한 용도|
|---|---|---|---|
|온디맨드|높음|없음|테스트, 개발|
|절감형 플랜|중간|없음|장기 운영 서비스|
|예약 인스턴스|낮음|없음|예측 가능한 워크로드|
|스팟 인스턴스|매우 낮음|있음|배치 작업, AI 학습|
|전용 호스트|매우 높음|없음|보안 및 규제 환경|

---

## 한 줄 정리

> EC2 구매 옵션은 비용과 안정성의 균형을 위한 선택지이며, 안정성이 중요하면 예약 인스턴스나 절감형 플랜을, 비용 절감이 중요하면 스팟 인스턴스를 사용한다.
