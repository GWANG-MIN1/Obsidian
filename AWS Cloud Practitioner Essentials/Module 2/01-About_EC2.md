## EC2란?

- EC2는 **Elastic Compute Cloud**의 약자
- AWS에서 제공하는 **가상 서버(VM) 서비스**
- 필요한 만큼 서버를 생성하고 즉시 사용할 수 있음

---

## 주요 특징

### 유연성 (Elastic)

- 서버 사양(CPU, 메모리 등)을 필요에 따라 변경 가능
- 사용량에 따라 인스턴스를 늘리거나 줄일 수 있음

### 비용 효율성

- **사용한 만큼 비용을 지불(Pay-as-you-go)**
- 초기 서버 구매 비용이 필요 없음

### 빠른 구축

- 몇 분 안에 서버 생성 및 사용 가능
- 물리 서버를 직접 구매하거나 설치할 필요가 없음

---

## 멀티 테넌시 (Multi-Tenancy)

- 여러 사용자의 가상 머신(VM)이 하나의 물리 서버를 공유
- 각 VM은 서로 독립적으로 동작
- 하드웨어 자원을 효율적으로 활용 가능

---

## 확장성 (Scaling)

**수직 확장 (Vertical Scaling)**

- 더 높은 성능의 인스턴스로 변경
- 예: CPU나 메모리 증가

**수평 확장 (Horizontal Scaling)**

- 서버 인스턴스 수를 늘리거나 줄임
- 트래픽 증가 시 여러 대의 서버를 추가하여 대응

---

## AWS가 담당하는 부분

- 데이터센터 구축 및 운영
- 물리 서버 구매 및 설치
- 네트워크 및 전원 관리
- 보안 및 유지보수

→ 사용자는 서버 관리보다 애플리케이션 개발과 운영에 집중할 수 있음

---

## CaaS (Compute as a Service)

- 서버를 직접 구매하지 않고 필요한 만큼 빌려서 사용
- 인터넷을 통해 컴퓨팅 자원을 즉시 제공받음
- 사용한 만큼만 비용을 지불

---

## 한 줄 정리

**EC2는 AWS가 관리하는 물리 서버 위에 가상 서버를 제공하여, 사용자가 필요한 만큼 컴퓨팅 자원을 빌려 쓰고 사용량만큼 비용을 지불하는 클라우드 서비스이다.**
