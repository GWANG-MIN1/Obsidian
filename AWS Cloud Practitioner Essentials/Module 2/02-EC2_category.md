# Amazon EC2 인스턴스 유형 (Instance Types)

EC2 인스턴스는 사용 목적에 따라 **인스턴스 패밀리(Instance Family)** 로 구분된다.

---

## 1. 범용 (General Purpose)

- CPU, 메모리, 네트워크 자원이 균형 있게 제공됨
- 다양한 일반적인 워크로드에 적합

**사용 예시**

- 웹 서버
- 애플리케이션 서버
- 개발 환경
- 코드 저장소(Git 서버)

---

## 2. 컴퓨팅 최적화 (Compute Optimized)

- CPU 성능이 중요한 작업에 적합
- 높은 연산 성능 제공

**사용 예시**

- 게임 서버
- 고성능 컴퓨팅(HPC)
- 과학 및 공학 시뮬레이션
- 대규모 연산 작업

---

## 3. 메모리 최적화 (Memory Optimized)

- 대용량 메모리가 필요한 작업에 적합
- 메모리 집약적인 애플리케이션에 사용

**사용 예시**

- 인메모리 데이터베이스
- 빅데이터 분석
- 실시간 데이터 처리

---

## 4. 가속 컴퓨팅 (Accelerated Computing)

- GPU나 하드웨어 가속기를 활용하는 작업에 적합
- 대량의 병렬 연산을 수행

**사용 예시**

- 머신러닝 및 AI
- 그래픽 렌더링
- 부동소수점 계산
- 데이터 패턴 분석
- 영상 처리

---

## 5. 스토리지 최적화 (Storage Optimized)

- 빠른 로컬 스토리지 성능 제공
- 대용량 데이터의 빠른 입출력이 필요한 경우 사용

**사용 예시**

- 데이터베이스
- 로그 처리 시스템
- 분산 파일 시스템
- 빅데이터 저장 및 분석

---

## 요금 특징

- 인스턴스 성능이 높을수록 비용이 증가
- CPU, 메모리, 스토리지 등의 자원을 많이 사용할수록 요금이 높아짐
- 사용 목적에 맞는 인스턴스를 선택하는 것이 비용 효율적

---

### 한 줄 정리

> EC2 인스턴스는 용도에 따라 여러 종류로 나뉘며, 더 높은 CPU·메모리·스토리지 성능을 사용할수록 비용도 함께 증가한다.
