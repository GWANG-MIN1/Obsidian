# AWS Support Plans (AWS 지원 플랜)

## AWS Support란?

AWS는 **기업 규모와 관계없이** 고객이 AWS를 안정적으로 사용할 수 있도록 다양한 **기술 지원(Support) 플랜**을 제공한다.

개인 사용자부터 스타트업, 중소기업, 대기업, 공공기관까지 요구사항에 맞는 지원 수준을 선택할 수 있다.

지원 플랜은 다음과 같이 구성된다.

- Basic Support
- Developer Support
- Business Support
- Enterprise On-Ramp Support
- Enterprise Support

---

# 1. Basic Support

모든 AWS 고객에게 **무료**로 제공되는 기본 지원 플랜이다.

### 주요 기능

- AWS 고객 모두 무료 제공
- AWS 문서 및 기술 자료 이용
- AWS Health Dashboard 이용
- AWS Service Health Dashboard 이용
- 24시간 서비스 상태 확인
- 계정 및 결제 지원

### 적합한 대상

- AWS를 처음 사용하는 사용자
- 개인 개발자
- 학습 목적

---

# 2. Developer Support

개발 및 테스트 환경을 위한 지원 플랜이다.

Basic Support의 모든 기능을 포함하며 기술 지원을 받을 수 있다.

### 주요 기능

- Basic Support의 모든 기능 포함
- 고객 지원 엔지니어에게 문의 가능
- 개발 및 테스트 환경 기술 지원
- 일반적인 기술 문의 지원

### 응답 시간

| 문제 수준 | 응답 시간 |
|-----------|-----------|
| 시스템 손상(Impaired System) | **12시간 이내** |

### 적합한 대상

- 개발자
- 개발 및 테스트 환경
- 비프로덕션 워크로드

---

# 3. Business Support

실제 운영(Production) 환경을 위한 가장 많이 사용되는 지원 플랜이다.

Developer Support의 모든 기능을 포함하며 운영 환경에 필요한 빠른 기술 지원을 제공한다.

### 주요 기능

- Developer Support의 모든 기능 포함
- **AWS Trusted Advisor** 전체 기능 제공
- AWS Support 엔지니어에게 24시간 문의 가능
- AWS 인프라 및 운영 관련 지원
- 모범 사례(Best Practices) 지원

### 응답 시간

| 문제 수준 | 응답 시간 |
|-----------|-----------|
| 프로덕션 시스템 장애 | **1시간 이내** |
| 프로덕션 문제 | **4시간 이내** |

### 적합한 대상

- 운영(Production) 서비스
- 기업 서비스
- 신규 서비스 출시
- 대규모 이벤트 운영

---

# 4. Enterprise On-Ramp Support

성장하는 기업을 위한 엔터프라이즈 수준의 지원 플랜이다.

Business Support보다 높은 수준의 기술 지원과 운영 지원을 제공한다.

### 주요 기능

- Business Support의 모든 기능 포함
- 운영 환경 최적화 지원
- 아키텍처 및 운영 관련 기술 지원
- 빠른 응답 시간
- AWS 전문가 지원 강화

### 적합한 대상

- 빠르게 성장하는 기업
- 대규모 운영 환경으로 확장 중인 조직

---

# 5. Enterprise Support

미션 크리티컬(Mission-Critical) 시스템을 운영하는 기업을 위한 최고 수준의 지원 플랜이다.

Enterprise On-Ramp Support의 모든 기능을 포함하며 AWS 전문가가 고객의 성공을 전담 지원한다.

### 주요 기능

- Enterprise On-Ramp Support의 모든 기능 포함
- **Technical Account Manager (TAM)** 제공
- AWS 전문가의 아키텍처 및 운영 지원
- 사전(Proactive) 기술 지원
- 고객 성공(Customer Success) 지원
- 비즈니스 및 기술 전략 지원

### Technical Account Manager (TAM)

TAM은 고객의 전담 기술 담당자로서

- 기술 상담
- 문제 해결 지원
- 운영 최적화
- AWS 활용 전략 제안

등을 수행하는 **기본 연락 창구(Single Point of Contact)** 역할을 한다.

### 적합한 대상

- 금융 서비스
- 의료 서비스
- 글로벌 서비스
- 24시간 운영되는 핵심 시스템
- 미션 크리티컬 워크로드

---

# AWS 추가 지원 리소스

AWS는 Support Plan 외에도 다양한 무료 지원 리소스를 제공한다.

### AWS re:Post

AWS 사용자와 전문가가 질문과 답변을 공유하는 커뮤니티 서비스

---

### AWS Trust & Safety Center

AWS의 보안, 신뢰성 및 안전 관련 정보를 제공하는 센터

---

### AWS Solutions Architect

AWS 아키텍처 설계 및 모범 사례를 지원하는 전문가

---

### AWS Professional Services

AWS 전문가가 직접 프로젝트 구축과 마이그레이션을 지원하는 컨설팅 서비스

---

### AWS 공식 문서 및 기술 자료

- AWS Documentation
- AWS Knowledge Center
- AWS Whitepapers
- AWS Well-Architected Framework

---

# 핵심 정리

- **Basic Support** : 모든 AWS 고객에게 무료로 제공되는 기본 지원 플랜
- **Developer Support** : 개발 및 테스트 환경을 위한 기술 지원 제공
- **Business Support** : 운영(Production) 환경을 위한 지원 플랜으로, Trusted Advisor 전체 기능과 빠른 기술 지원 제공
- **Enterprise On-Ramp Support** : 성장하는 기업을 위한 엔터프라이즈 수준의 지원 플랜
- **Enterprise Support** : 최고 수준의 지원 플랜으로, **Technical Account Manager(TAM)** 를 통해 전담 기술 지원을 제공
- AWS는 **re:Post, Trust & Safety Center, Solutions Architect, Professional Services** 등 다양한 추가 지원 리소스도 제공한다.
