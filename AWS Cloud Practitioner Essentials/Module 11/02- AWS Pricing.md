# AWS 요금(Pricing) 기본 개념

## AWS 요금 모델이란?

AWS는 **사용한 만큼 비용을 지불하는(Pay-as-you-go)** 클라우드 요금 모델을 제공한다.

초기 인프라 구매 비용 없이 필요한 만큼 리소스를 사용하고, 사용량에 따라 비용을 지불한다.

AWS의 요금 모델은 크게 **3가지 기본 원칙**으로 구성된다.

---

# AWS 요금의 3가지 기본 원칙

## 1. 종량제 요금 (Pay-as-you-go)

가장 기본적인 과금 방식이다.

필요한 만큼 AWS 리소스를 사용하고 **사용한 만큼만 비용을 지불**한다.

### 특징

- 선결제 비용 없음
- 장기 약정 없음
- 언제든지 사용 시작 및 종료 가능
- 사용한 리소스에 대해서만 비용 지불

### 적합한 워크로드

- 개발 및 테스트 환경
- 트래픽 변동이 큰 서비스
- 단기 프로젝트
- 예측하기 어려운 워크로드

---

## 2. 장기 약정을 통한 비용 절감 (Save when you commit)

AWS는 일정 기간 리소스 사용을 약정하면 할인된 요금을 제공한다.

대표적으로

- **1년 약정**
- **3년 약정**

을 선택할 수 있다.

예시

- Reserved Instances (RI)
- Savings Plans

### 특징

- 장기 약정 시 할인
- 안정적인 워크로드에 적합
- 지속적으로 사용하는 리소스일수록 비용 절감 효과가 큼

### 적합한 워크로드

- 운영(Production) 서버
- 데이터베이스
- 항상 실행되는 EC2 인스턴스

---

## 3. 사용량이 많을수록 비용 절감 (Pay less by using more)

AWS는 많은 서비스를 대상으로 **볼륨 기반 할인(Volume Discount)** 을 제공한다.

즉,

> **사용량이 증가할수록 단위당 비용이 낮아질 수 있다.**

### 예시

- Amazon S3 스토리지
- 데이터 전송
- CloudFront

---

# AWS 주요 비용 발생 요소

AWS의 비용은 사용하는 서비스에 따라 달라진다.

서비스마다 과금 기준이 다르므로 **공식 요금 정책을 확인하는 것이 중요하다.**

대표적인 비용 발생 요소는 다음과 같다.

---

## 1. 컴퓨팅 (Compute)

대표 서비스

- Amazon EC2
- AWS Lambda
- Amazon ECS
- Amazon EKS

주요 과금 기준

- 인스턴스 종류
- CPU 및 메모리 사양
- 실행 시간
- 사용한 컴퓨팅 용량

예시

EC2 인스턴스를 10시간 실행하면 **10시간에 대한 비용**이 발생한다.

---

## 2. 스토리지 (Storage)

대표 서비스

- Amazon S3
- Amazon EBS
- Amazon EFS

주요 과금 기준

- 저장된 데이터 용량
- 저장 기간
- 스토리지 클래스

예시

S3에 100GB의 데이터를 한 달 동안 저장하면 **100GB × 1개월**에 대한 비용이 발생한다.

---

## 3. 데이터 전송 (Data Transfer)

AWS에서는 특히 **아웃바운드(Outbound) 데이터 전송**에 비용이 발생하는 경우가 많다.

### 아웃바운드 데이터 전송

AWS에서 인터넷 또는 외부 네트워크로 데이터를 전송하는 경우 발생하는 비용이다.

예시

- S3 정적 웹사이트 호스팅
- CloudFront를 사용하지 않고 인터넷으로 파일 다운로드
- EC2에서 인터넷으로 데이터 전송

예를 들어 S3 버킷을 정적 웹사이트로 운영하는 경우,

사용자가 웹사이트의 파일(객체)을 다운로드하거나 조회할 때마다 **인터넷으로 전송된 데이터 양에 따라 요금이 부과**될 수 있다.

> ※ 일부 서비스에서는 인바운드(Inbound) 데이터 전송은 무료이고, 아웃바운드 데이터 전송에만 요금이 부과된다.

---

# 서비스마다 과금 방식이 다르다

AWS 서비스마다 과금 기준이 다르므로 반드시 공식 문서를 확인해야 한다.

예를 들어

| 서비스 | 주요 과금 기준 |
|---------|----------------|
| Amazon EC2 | 인스턴스 유형, 실행 시간 |
| Amazon S3 | 저장 용량, 요청 수, 데이터 전송 |
| AWS Lambda | 호출 횟수, 실행 시간 |
| Amazon RDS | 인스턴스 사양, 스토리지, 백업 |
| Amazon CloudFront | 데이터 전송량, 요청 수 |

---

# 핵심 정리

- AWS는 **종량제(Pay-as-you-go)** 방식으로 사용한 만큼만 비용을 지불한다.
- 장기 사용이 예상되는 리소스는 **1년 또는 3년 약정(Reserved Instances, Savings Plans)** 을 통해 비용을 절감할 수 있다.
- 일부 서비스는 **사용량이 많을수록 단가가 낮아지는 볼륨 기반 할인**을 제공한다.
- AWS 비용은 주로 **컴퓨팅, 스토리지, 데이터 전송**에 의해 결정된다.
- 서비스마다 과금 기준이 다르므로 **공식 요금 정책과 문서를 확인하는 것이 중요하다.**
