# AWS Marketplace & AWS Partner Network (APN)

# AWS Marketplace

## AWS Marketplace란?

**AWS Marketplace**는 AWS 환경에서 실행할 수 있는 **서드파티(Third-party) 소프트웨어와 서비스를 검색, 구매, 배포 및 관리**할 수 있는 디지털 카탈로그이다.

AWS Marketplace를 이용하면 다양한 공급업체(Vendor)가 제공하는 솔루션을 손쉽게 선택하여 AWS 계정에 배포할 수 있다.

쉽게 말하면,

> **AWS에서 사용할 수 있는 서드파티 소프트웨어를 구매하고 바로 배포할 수 있는 온라인 마켓**이다.

---

# AWS Marketplace의 특징

- 검증된 서드파티 소프트웨어 제공
- AWS 환경에 손쉽게 배포
- AWS 계정으로 통합 결제
- 다양한 라이선스 및 구독 방식 지원
- 구매부터 배포, 관리까지 하나의 플랫폼에서 수행

---

# AWS Marketplace의 장점

### 1. 총소유비용(TCO) 절감

필요한 소프트웨어를 빠르게 도입하여 구축 및 운영 비용을 줄일 수 있다.

---

### 2. 혁신 가속화

필요한 솔루션을 즉시 사용할 수 있어 서비스 개발과 출시 속도를 높일 수 있다.

---

### 3. 조달 프로세스 간소화

소프트웨어 구매 절차를 단순화하여 복잡한 계약 및 구매 과정을 줄여준다.

---

### 4. 빠른 배포 및 확장

AWS 환경에 몇 번의 클릭만으로 소프트웨어를 배포하고 필요에 따라 손쉽게 확장(Scaling)할 수 있다.

---

### 5. AWS 계정으로 통합 결제

Marketplace에서 구매한 소프트웨어 비용은 **AWS 사용 요금과 함께 하나의 청구서로 결제**할 수 있다.

---

# AWS Marketplace에서 제공하는 솔루션

AWS Marketplace에서는 다양한 분야의 소프트웨어와 서비스를 제공한다.

### SaaS (Software as a Service)

- CRM
- 협업 도구
- 보안 서비스
- 생산성 도구

---

### Machine Learning (ML) & AI

- AI 모델
- 데이터 분석 도구
- 머신러닝 플랫폼
- 생성형 AI 솔루션

---

### Data & Analytics

- 데이터베이스
- 데이터 분석 플랫폼
- ETL 도구
- 데이터 시각화 솔루션

---

# AWS Marketplace 사용 사례

- 보안 솔루션 도입
- 데이터 분석 플랫폼 구축
- AI/ML 서비스 활용
- 기업용 SaaS 구독
- 개발 도구 및 모니터링 솔루션 배포

---

# AWS Partner Network (APN)

## AWS Partner Network(APN)란?

**AWS Partner Network(APN)** 는 AWS 고객을 위한 솔루션을 구축하고 제공하는 **글로벌 파트너 프로그램**이다.

AWS는 다양한 기업과 협력하여 고객이 AWS를 효과적으로 도입하고 운영할 수 있도록 지원한다.

쉽게 말하면,

> **AWS와 협력하는 글로벌 기업 및 전문가들의 파트너 생태계**이다.

---

# APN의 목적

- 고객의 AWS 도입 지원
- AWS 기반 솔루션 개발
- 전문 기술 서비스 제공
- AWS 생태계 확대

AWS의 가장 큰 목표는 고객이 AWS를 성공적으로 활용할 수 있도록 지원하는 것이다.

---

# AWS 파트너가 되는 장점

### 1. 자금 지원(Funding)

AWS에서 제공하는 다양한 공동 마케팅 및 프로젝트 지원 프로그램을 활용할 수 있다.

---

### 2. AWS 파트너 이벤트

파트너 전용

- 컨퍼런스
- 세미나
- 네트워킹 행사

등에 참여할 수 있다.

---

### 3. 교육 및 자격증 지원

AWS에서는 파트너에게

- 기술 교육
- 비즈니스 교육
- AWS 자격증(AWS Certification)

취득을 지원하는 다양한 프로그램을 제공한다.

---

# APN 파트너 유형

대표적인 파트너 유형

- **Consulting Partner** : AWS 도입 및 구축 컨설팅 제공
- **Technology Partner** : AWS에서 실행되는 소프트웨어 및 솔루션 개발

---

# AWS Marketplace vs AWS Partner Network

| 서비스 | 목적 |
|---------|------|
| **AWS Marketplace** | AWS에서 사용할 수 있는 서드파티 소프트웨어와 서비스를 검색, 구매 및 배포하는 디지털 카탈로그 |
| **AWS Partner Network(APN)** | AWS 고객을 위한 솔루션과 서비스를 제공하는 글로벌 파트너 생태계 및 프로그램 |

---

# 핵심 정리

- **AWS Marketplace**는 AWS 환경에서 사용할 수 있는 **서드파티 소프트웨어와 서비스를 검색, 구매, 배포 및 관리**할 수 있는 디지털 카탈로그이다.
- AWS Marketplace를 사용하면 **총소유비용(TCO)을 절감**하고, 소프트웨어를 빠르게 배포하며, **AWS 계정으로 통합 결제**할 수 있다.
- Marketplace에서는 **SaaS, Machine Learning & AI, Data & Analytics** 등 다양한 솔루션을 제공한다.
- **AWS Partner Network(APN)** 는 AWS 고객을 위한 솔루션을 구축하고 제공하는 **글로벌 파트너 프로그램**이다.
- APN 파트너는 **자금 지원, 파트너 전용 이벤트, 교육 및 AWS 자격증 지원** 등의 다양한 혜택을 받을 수 있다.
