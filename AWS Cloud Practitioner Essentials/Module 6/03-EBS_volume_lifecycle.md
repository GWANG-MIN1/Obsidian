# EBS Snapshot

> **EBS 볼륨의 특정 시점(Point-in-Time) 백업**

### 특징
- EBS 볼륨의 데이터를 특정 시점으로 백업
- Amazon S3에 증분(Incremental) 방식으로 저장
- 필요한 시점에 새로운 EBS 볼륨으로 복원 가능

### 활용 사례
- 재해 복구(Disaster Recovery)
- 데이터 백업 및 복구
- 데이터 마이그레이션
- EBS 볼륨 크기 조정
- 프로덕션 워크로드의 일관성 있는 백업 생성

### 장점
- 데이터 보호 및 복구
- 운영 유연성 향상
- 비용 효율성
- 빠른 복원 및 재사용

### 한 줄 요약
> **EBS 볼륨을 원하는 시점으로 되돌릴 수 있는 백업 기능**

# Amazon Data Lifecycle Manager (DLM)

> **EBS 스냅샷과 AMI의 수명 주기를 자동으로 관리하는 서비스**

### 기능
- EBS 스냅샷 자동 생성
- 스냅샷 자동 보존
- 오래된 스냅샷 자동 삭제
- 백업 정책 자동화

### 장점
- 백업 관리 자동화
- 운영 부담 감소
- 불필요한 스냅샷 삭제로 비용 절감
- 규칙적인 백업 정책 유지

### 한 줄 요약
> **EBS 스냅샷을 자동으로 생성·보관·삭제해 주는 서비스**
