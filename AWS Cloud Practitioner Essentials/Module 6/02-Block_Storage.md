# 블록 스토리지

## Amazon EC2 Instance Store

> EC2 인스턴스가 실행되는 **호스트 컴퓨터에 물리적으로 연결된 블록 스토리지**

### 특징
- EC2와 함께 제공되는 로컬(Local) 디스크
- 매우 높은 성능과 낮은 지연 시간
- 별도의 비용 없이 자동으로 사용 가능(지원 인스턴스)

### 데이터 지속성
- ❌ 데이터 지속성 없음
- EC2 인스턴스가 **중지(Stop)** 또는 **종료(Terminate)** 되면 데이터가 손실됨

### 사용 사례
- 버퍼(Buffer)
- 캐시(Cache)
- 스크래치 데이터(Scratch Data)
- 임시 파일
- 중간 계산 결과

### 사용하지 않는 경우
- 데이터 보존이 필요한 애플리케이션
- 데이터베이스
- 영구 파일 저장

### 한 줄 요약
> **빠르지만 데이터가 사라지는 임시 디스크**

## Amazon Elastic Block Store (Amazon EBS)

> EC2 인스턴스에서 사용하는 **영구(Persistent) 블록 스토리지**

### 특징
- EC2에 연결하는 외장 하드디스크처럼 동작
- 낮은 지연 시간과 일관된 성능 제공
- 운영체제 및 데이터베이스 저장에 적합

### 데이터 지속성
- ✅ 데이터 지속성 제공
- EC2를 중지하거나 재시작해도 데이터 유지
- EBS 볼륨은 EC2와 분리하여 관리 가능

### 주요 사용 사례
- 운영체제(OS)
- 데이터베이스(DB)
- 파일 시스템(File System)
- 애플리케이션 데이터 저장

### 장점
- 데이터 마이그레이션(Migration)
- 인스턴스 유형 변경
- 재해 복구(Disaster Recovery)
- 비용 최적화
- 성능 튜닝

### 한 줄 요약
> **외장 하드디스크처럼 사용하는 영구 스토리지**
