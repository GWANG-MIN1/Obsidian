# Amazon Simple Storage Service (Amazon S3)

> **인터넷을 통해 원하는 양의 데이터를 저장하고 검색할 수 있는 완전관리형 객체(Object) 스토리지 서비스**

## 특징

- 데이터를 **객체(Object)** 형태로 저장
- 객체는 **버킷(Bucket)** 에 저장
  - 버킷 = 객체를 저장하는 최상위 컨테이너(폴더와 비슷한 개념)
- 객체 하나당 최대 **5TB** 업로드 가능
- 여러 개의 버킷 생성 가능
- 객체 버전 관리(Versioning) 지원
- 거의 무제한으로 확장 가능
- 여러 가용 영역(AZ)에 자동 저장되어 **99.999999999%(11 9's)** 데이터 내구성 제공

### 한 줄 요약
> **용량 걱정 없이 데이터를 저장하는 객체 스토리지**

---

# 주요 활용 사례

- 이미지, 동영상 등 미디어 파일 저장
- 정적 웹 사이트 호스팅
- 데이터 백업 및 복구
- 로그 파일 저장
- 데이터 아카이브
- 데이터 레이크 구축

### 장점
- 필요에 따라 자동 확장(Scale Up/Down)
- 높은 내구성과 가용성
- 비용 효율적인 데이터 저장

# Amazon S3 보안

## 기본 보안

- 기본적으로 모든 버킷과 객체는 **비공개(Private)**

## 버킷 정책 (Bucket Policy)

- 버킷 단위 접근 권한 관리
- 특정 사용자 또는 서비스에 접근 허용/거부

## 사전 서명된 URL (Pre-signed URL)

- 일정 시간 동안만 객체 접근 가능
- 외부 사용자에게 안전하게 파일 공유 가능

## Amazon S3 Access Points

- 공유 데이터셋에 대한 접근 정책을 간소화
- 애플리케이션 또는 사용자별 접근 지점 제공
- 대규모 데이터 공유 환경에 적합

## S3 감사 로그 (Logging)

- S3 객체에 대한 요청 기록
- 누가 언제 어떤 객체에 접근했는지 추적 가능
- 보안 감사 및 문제 분석에 활용
