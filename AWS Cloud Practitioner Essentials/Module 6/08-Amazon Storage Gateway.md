# Amazon Storage Gateway

> **온프레미스(On-Premises) 환경과 AWS 스토리지를 연결하는 하이브리드 스토리지 서비스**

## 주요 기능

- 재해 복구(Disaster Recovery)
- 데이터 백업
- 데이터 아카이빙
- 로컬 스토리지의 클라우드 확장

### 장점

- 온프레미스와 AWS의 원활한 통합
- 데이터 관리 간소화
- 로컬 캐싱으로 빠른 접근
- 스토리지 비용 최적화

---

# Storage Gateway 종류

## 1. Amazon S3 File Gateway

> **파일(File) 데이터를 Amazon S3에 저장**

### 특징
- NFS / SMB 지원
- 파일을 Amazon S3 객체로 저장
- 로컬 캐시 제공

### 사용 사례
- 파일 공유
- 로그 저장
- 백업

---

## 2. Volume Gateway

> **온프레미스에서 블록 스토리지를 제공하고 AWS에 백업하는 서비스**

### 특징
- iSCSI 블록 스토리지 제공
- 데이터 스냅샷을 AWS에 저장
- 재해 복구에 적합

### 모드

#### Cached Volume
- 대부분의 데이터는 AWS 저장
- 자주 사용하는 데이터만 로컬 캐시

#### Stored Volume
- 데이터는 로컬에 저장
- AWS에는 백업(스냅샷) 저장

---

## 3. Tape Gateway

> **기존 물리적 테이프 라이브러리를 가상 테이프로 대체하는 서비스**

### 특징
- 기존 백업 소프트웨어 그대로 사용
- 백업 데이터를 AWS에 저장
- 장기 보관 및 아카이빙에 적합
