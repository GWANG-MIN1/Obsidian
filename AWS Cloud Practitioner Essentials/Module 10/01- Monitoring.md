# AWS 모니터링 (Monitoring)

## 모니터링(Monitoring)이란?

- 시스템을 지속적으로 관찰(Observe)하는 것
- CPU, 메모리, 네트워크 사용량 등의 **지표(Metrics)** 를 수집하는 것
- 수집한 데이터를 분석하여 **의사결정을 내리는 것**

> **Monitoring = 시스템을 관찰하고, 지표를 수집하며, 데이터를 기반으로 의사결정을 내리는 과정**

---

# 클라우드에서 모니터링이 중요한 이유

클라우드 환경은 리소스를 필요에 따라 **동적으로 확장(Scale Up)** 하거나 **축소(Scale Down)** 할 수 있다.

따라서 현재 시스템이 정상적으로 동작하는지 지속적으로 확인하는 것이 매우 중요하다.

---

# 모니터링 활용 예시

### 1. Auto Scaling

- EC2 인스턴스의 CPU 사용률이 일정 수준 이상으로 증가
- Auto Scaling이 이를 감지
- 새로운 EC2 인스턴스를 자동으로 생성하여 트래픽 분산

**예시**

```
CPU 사용률 85%
        ↓
CloudWatch 모니터링
        ↓
Auto Scaling 실행
        ↓
새로운 EC2 인스턴스 생성
```

---

### 2. 장애 알림(Notification)

애플리케이션이 비정상적인 오류를 발생시키기 시작하면

- 관리자 또는 운영팀에게 자동으로 알림을 전송
- 문제를 빠르게 확인하고 대응 가능

**예시**

```
애플리케이션 오류 증가
        ↓
CloudWatch Alarm 발생
        ↓
SNS를 통해 운영자에게 알림
        ↓
문제 확인 및 해결
```

---

# AWS 모니터링 도구의 역할

AWS의 모니터링 서비스를 사용하면 다음과 같은 작업을 수행할 수 있다.

- 시스템 성능 측정
- 리소스 상태 모니터링
- 오류 및 이상 징후 감지
- 알람(Alert) 생성 및 알림 전송
- 장애 원인 디버깅(Debugging)
- 문제 해결(Troubleshooting)

---

# 핵심 정리

- **Monitoring** = 시스템을 관찰하고 데이터를 수집하여 상태를 파악하는 것
- 클라우드에서는 리소스가 동적으로 변하므로 모니터링이 필수
- 이상 상황 발생 시 자동 확장(Auto Scaling) 및 알림(Notification) 수행 가능
- AWS 모니터링 도구를 활용하면 성능 측정, 장애 감지, 디버깅, 문제 해결까지 효율적으로 수행할 수 있다.
