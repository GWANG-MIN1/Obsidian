# AWS 규정 준수(Compliance)

## 규정 준수(Compliance)란?

**규정 준수(Compliance)** 란 기업이나 조직이 법률, 규제, 산업 표준 및 보안 정책을 준수하는 것을 의미한다.

산업마다 반드시 따라야 하는 규정이 있으며, 이를 준수하는지 **감사(Audit)** 또는 **검사(Assessment)** 를 받을 수 있다.

---

# 규정 준수 사례

### GDPR (General Data Protection Regulation)

유럽연합(EU)에서 소비자의 개인정보를 처리하는 경우에는 **GDPR**을 준수해야 한다.

주요 목적
- 개인정보 보호
- 개인정보 처리의 투명성 확보
- 사용자 데이터 권리 보호

---

### HIPAA (Health Insurance Portability and Accountability Act)

미국에서 의료 서비스를 운영하거나 의료 데이터를 처리하는 애플리케이션은 **HIPAA**를 준수해야 한다.

주요 목적
- 의료 정보 보호
- 환자 개인정보 보안 유지

따라서 의료 애플리케이션을 구축할 경우 HIPAA 요구사항을 만족하도록 시스템 아키텍처를 설계해야 한다.

# AWS와 규정 준수

AWS는 다양한 국제 및 산업 규정을 충족하는 인프라를 제공한다.

AWS 고객은 AWS가 제공하는

- 보안 정책
- 인프라
- 모범 사례(Best Practices)

를 그대로 활용할 수 있다.

즉,

> **AWS가 담당하는 인프라 규정 준수는 이미 충족되어 있으므로, 고객은 자신의 애플리케이션과 데이터가 규정을 준수하도록 구성하는 데 집중하면 된다.**

---

# AWS 공동 책임 모델과 규정 준수

AWS 공동 책임 모델에서는

### AWS의 책임

- 데이터센터 보안
- 물리적 인프라
- 네트워크
- 하드웨어
- 기본 클라우드 인프라 보안

### 고객의 책임

- 고객 데이터 보호
- IAM 권한 관리
- 암호화 설정
- 리소스 보안 설정
- 운영체제 및 애플리케이션 구성

즉,

> **고객 데이터 보호에 대한 책임은 전적으로 고객에게 있다.**

---

# 리전(Region) 선택

서비스를 운영할 때는 **규정 준수를 만족하는 AWS 리전**을 선택해야 한다.

예를 들어

- 특정 국가에서 데이터를 해당 국가 내에만 저장해야 하는 경우
- 특정 지역에서만 서비스를 운영해야 하는 경우

적절한 리전을 선택하여 규정을 충족할 수 있다.

> AWS는 데이터를 모든 리전에 자동으로 복제하지 않는다.

# AWS Artifact

**AWS Artifact**는 AWS의 **보안 및 규정 준수 관련 문서**를 온디맨드(On-Demand)로 제공하는 무료 서비스이다.

제공 내용

- 보안 보고서
- 규정 준수 보고서
- 인증 문서
- 일부 온라인 계약

필요할 때 언제든지 다운로드하여 확인할 수 있다.

---

# AWS Artifact의 이점

- 무료 서비스
- 규정 준수 보고서 즉시(On-Demand) 확인
- 대규모 계약 관리 가능
- 시간 절약
- 보다 신뢰성 있는 서비스 배포 지원

---

# AWS Artifact 사용 사례

- 일부 온라인 계약 관리
- 보안 감사 자료 확보
- 제3자(Third Party) 보안 및 규정 준수 평가
- 규제 기관 제출 자료 활용

---

# AWS Artifact의 구성

AWS Artifact는 두 가지 유형으로 구성된다.

### 1. AWS Artifact Agreements

- AWS와 체결하는 온라인 계약
- 규정 준수와 관련된 계약 문서 제공

예시
- Business Associate Addendum(BAA)
- Data Processing Addendum(DPA)

---

### 2. AWS Artifact Reports

AWS가 획득한 다양한 인증 및 감사 보고서를 제공한다.

예시
- SOC Reports
- ISO 인증
- PCI DSS 보고서

---

# AWS 규정 준수 센터 (AWS Compliance Center)

AWS 규정 준수와 관련된 다양한 정보를 한 곳에서 제공하는 사이트이다.

제공 내용

- 규정 준수 프로그램 소개
- 보안 백서(Security Whitepapers)
- 인증 정보
- 규정 준수 관련 FAQ
- 모범 사례(Best Practices)

---

# AWS 규정 준수의 장점

- AWS가 사용하는 최신 보안 제어(Security Controls)를 동일하게 활용 가능
- 제3자(Third Party)가 수천 개의 글로벌 규정 준수 여부를 검증
- 규정 준수 작업을 간소화하고 자동화
- 필요 시 온디맨드(On-Demand) 규정 준수 보고서 제공

---

# AWS 규정 준수(Compliance) 페이지

AWS 규정 준수 페이지에서는 다음과 같은 정보를 확인할 수 있다.

- 핵심 규정 준수 관련 질문에 대한 AWS의 답변
- AWS 위험(Risk) 및 규정 준수 개요
- 보안 감사(Security Audit) 체크리스트
- 각종 인증 및 규정 준수 프로그램 소개

---

# 핵심 정리

- **Compliance** : 법률, 규제 및 산업 표준을 준수하는 것
- AWS는 인프라 수준의 규정 준수를 제공하며, 고객은 자신의 데이터와 애플리케이션에 대한 규정 준수를 책임진다.
- 서비스 운영 시 규정을 충족하는 **AWS 리전**을 선택해야 한다.
- **AWS Artifact** : 보안 및 규정 준수 보고서와 계약 문서를 제공하는 무료 서비스
  - **Artifact Agreements** : 온라인 계약
  - **Artifact Reports** : 보안 및 규정 준수 보고서
- **AWS Compliance Center** : 규정 준수 정보, 보안 백서 및 인증 자료를 한곳에서 제공하는 사이트
