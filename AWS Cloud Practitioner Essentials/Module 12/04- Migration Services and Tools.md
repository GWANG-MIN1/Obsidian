# AWS 마이그레이션 서비스 (AWS Migration Services)

## AWS 마이그레이션 서비스란?

AWS는 기업이 **애플리케이션과 데이터를 AWS 클라우드로 쉽고 안전하게 이전**할 수 있도록 다양한 마이그레이션 서비스를 제공한다.

대표적인 서비스는 다음과 같다.

- AWS Application Discovery Service
- AWS Application Migration Service
- AWS Migration Evaluator
- AWS Migration Hub

이러한 서비스는 마이그레이션의 **계획 → 평가 → 실행 → 관리** 전 과정을 지원한다.

---

# 1. AWS Application Discovery Service

## AWS Application Discovery Service란?

**AWS Application Discovery Service**는 현재 IT 환경을 자동으로 분석하여 **마이그레이션 계획 수립에 필요한 정보를 수집하는 서비스**이다.

쉽게 말하면,

> **마이그레이션을 위한 '탐정'처럼 현재 IT 환경을 조사하고 분석하는 서비스**이다.

### 주요 기능

- 서버 자동 검색
- 애플리케이션 분석
- 서버 간 종속성(Dependency) 분석
- 시스템 구성 정보 수집
- 리소스 사용 현황 분석
- 상세 보고서 생성

### 장점

- 무엇을 이전할지 파악 가능
- 애플리케이션 간 연관 관계 분석
- 효과적인 마이그레이션 계획 수립
- 정보에 기반한 의사결정 지원

---

# 2. AWS Application Migration Service (MGN)

## AWS Application Migration Service란?

**AWS Application Migration Service(MGN)** 는 기존 애플리케이션을 AWS로 **자동화되고 신속하게 이전**할 수 있도록 지원하는 서비스이다.

쉽게 말하면,

> **전문 마이그레이션 팀처럼 애플리케이션을 AWS로 안전하게 이전해 주는 서비스**이다.

### 주요 기능

- 서버 복제
- 애플리케이션 자동 마이그레이션
- 최소한의 다운타임
- 다양한 운영체제 지원
- 물리 서버 및 가상 머신(VM) 이전

### 장점

- 마이그레이션 자동화
- 빠른 이전
- 운영 중단 시간 최소화
- 위험 감소

---

# 3. AWS Migration Evaluator

## AWS Migration Evaluator란?

**AWS Migration Evaluator**는 현재 IT 환경을 분석하여 **AWS로 이전할 경우의 예상 비용과 절감 효과를 분석하는 서비스**이다.

쉽게 말하면,

> **이사 비용을 미리 계산해 주는 전문가처럼 마이그레이션 비용과 경제성을 분석하는 서비스**이다.

### 주요 기능

- 현재 IT 환경 분석
- AWS 이전 비용 예측
- 비용 절감 효과 분석
- 총소유비용(TCO) 분석
- 투자 타당성(ROI) 분석

### 장점

- 예산 계획 수립
- 데이터 기반 의사결정
- 투자 근거 제공
- 경영진 보고 자료 활용

---

# 4. AWS Migration Hub

## AWS Migration Hub란?

**AWS Migration Hub**는 여러 마이그레이션 작업을 **하나의 중앙 콘솔에서 관리하고 진행 상황을 추적하는 서비스**이다.

쉽게 말하면,

> **전체 마이그레이션 프로젝트의 '지휘 본부(Control Tower)' 역할을 하는 서비스**이다.

### 주요 기능

- 마이그레이션 진행 상황 관리
- 프로젝트 추적
- 여러 AWS 마이그레이션 서비스 통합 관리
- 작업 상태 모니터링
- 리소스 현황 확인

### 장점

- 체계적인 프로젝트 관리
- 누락 방지
- 진행 상황 가시성 향상
- 여러 서비스 통합 관리

# AWS 마이그레이션 서비스 비교

| 서비스 | 주요 역할 | 쉽게 이해하기 |
|---------|-----------|---------------|
| **AWS Application Discovery Service** | 현재 IT 환경 분석 및 종속성 조사 | 🕵️ 마이그레이션 탐정 |
| **AWS Application Migration Service (MGN)** | 애플리케이션을 AWS로 자동 이전 | 🚚 전문 이사팀 |
| **AWS Migration Evaluator** | 비용 및 경제성 분석 | 💰 이사 비용 견적 전문가 |
| **AWS Migration Hub** | 전체 마이그레이션 프로젝트 관리 | 🎯 마이그레이션 지휘 본부 |

# AWS 마이그레이션 서비스의 이점

- 마이그레이션 프로세스 간소화
- 오류 및 다운타임 감소
- 비용 절감
- 빠른 마이그레이션 수행
- 프로젝트 진행 상황 관리
- 가치 창출 시간(Time to Value) 단축

---

# 핵심 정리

- AWS는 **Application Discovery Service, Application Migration Service(MGN), Migration Evaluator, Migration Hub** 등 다양한 마이그레이션 서비스를 제공한다.
- **Application Discovery Service**는 현재 IT 환경과 애플리케이션 종속성을 분석하여 마이그레이션 계획 수립을 지원한다.
- **Application Migration Service(MGN)** 는 애플리케이션을 AWS로 자동화되고 신속하게 이전하며, 다운타임을 최소화한다.
- **Migration Evaluator**는 AWS 이전 비용과 **총소유비용(TCO)** 절감 효과를 분석하여 예산 계획과 투자 타당성 평가를 지원한다.
- **Migration Hub**는 여러 마이그레이션 작업을 하나의 콘솔에서 관리하고 진행 상황을 추적하는 중앙 관리 서비스이다.
- 이러한 서비스는 **마이그레이션 프로세스 간소화, 오류 및 가동 중단 시간 감소, 비용 절감, 가치 창출 시간(Time to Value) 단축**에 도움을 준다.
