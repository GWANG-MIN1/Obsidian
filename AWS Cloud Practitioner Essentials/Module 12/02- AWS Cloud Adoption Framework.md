# AWS Cloud Adoption Framework (AWS CAF)

## AWS Cloud Adoption Framework(AWS CAF)란?

**AWS Cloud Adoption Framework(AWS CAF)** 는 기업이 AWS 클라우드로 성공적으로 마이그레이션하고 클라우드를 도입할 수 있도록 지원하는 프레임워크이다.

클라우드 마이그레이션은 단순히 시스템을 이전하는 작업이 아니라 **조직, 사람, 프로세스, 기술**이 함께 변화해야 하는 과정이다.

AWS CAF는 이러한 변화를 체계적으로 관리할 수 있도록 가이드라인을 제공한다.

쉽게 말하면,

> **기업이 AWS 클라우드를 성공적으로 도입하기 위한 조직 차원의 지침과 모범 사례를 제공하는 프레임워크**이다.

---

# AWS CAF가 필요한 이유

조직마다 역할과 책임이 다르기 때문에 클라우드 마이그레이션을 바라보는 관점도 서로 다르다.

예를 들어

- 경영진은 비즈니스 효과를 중요하게 생각한다.
- 보안팀은 보안 정책을 중요하게 생각한다.
- 운영팀은 서비스 운영 안정성을 중요하게 생각한다.
- 개발팀은 플랫폼과 개발 환경을 중요하게 생각한다.

AWS CAF는 이러한 다양한 관점을 하나의 프레임워크로 통합하여 성공적인 클라우드 도입을 지원한다.

---

# AWS CAF의 6가지 관점(Perspectives)

AWS CAF는 **6개의 관점(Perspectives)** 으로 구성된다.

## 1. 비즈니스(Business)

비즈니스 목표와 투자 효과를 중심으로 클라우드 도입 전략을 수립한다.

주요 내용

- 비즈니스 가치
- 투자 효과(ROI)
- 비용 절감
- 비즈니스 전략

---

## 2. 인력(People)

클라우드 도입에 필요한 조직과 인력을 준비한다.

주요 내용

- 조직 변화 관리
- 교육 및 역량 강화
- 역할과 책임 정의
- 기술 습득

---

## 3. 거버넌스(Governance)

클라우드 운영 정책과 관리 체계를 수립한다.

주요 내용

- 정책 수립
- 규정 준수(Compliance)
- 위험 관리
- 비용 관리

---

## 비즈니스 역량(Business Capabilities)

다음 3가지 관점은 **비즈니스 역량**에 중점을 둔다.

- Business
- People
- Governance

---

## 4. 플랫폼(Platform)

AWS 환경과 기술 인프라를 구축한다.

주요 내용

- 네트워크
- 컴퓨팅
- 스토리지
- 데이터베이스
- 마이그레이션

---

## 5. 보안(Security)

안전한 클라우드 환경을 구축한다.

주요 내용

- IAM
- 암호화
- 네트워크 보안
- 보안 정책

---

## 6. 운영(Operations)

클라우드 환경을 안정적으로 운영하고 관리한다.

주요 내용

- 모니터링
- 자동화
- 운영 절차
- 장애 대응

---

## 기술 역량(Technical Capabilities)

다음 3가지 관점은 **기술 역량**에 중점을 둔다.

- Platform
- Security
- Operations

---

# AWS CAF 실행 과정

각 관점에서는 현재 조직의 상태를 분석하여 **기술적·프로세스적 격차(Gap)** 를 파악한다.

이러한 분석 결과는 **AWS CAF 실행 계획(Action Plan)** 을 수립하기 위한 입력 자료로 활용된다.

```
현재 조직 분석

↓

기술 및 프로세스 격차(Gap) 식별

↓

AWS CAF 실행 계획(Action Plan)

↓

클라우드 마이그레이션 및 조직 변화
```

---

# AWS CAF 실행 계획(Action Plan)

AWS CAF 실행 계획은 조직이 클라우드로 전환하는 과정을 안내하는 로드맵이다.

주요 목적

- 클라우드 도입 전략 수립
- 조직 변화 관리
- 기술 및 프로세스 개선
- 마이그레이션 성공 지원

이를 통해 조직은 체계적으로 AWS 환경으로 전환할 수 있다.

---

# AWS CAF의 장점

- 조직 전체의 클라우드 도입 전략 수립
- 역할과 책임 명확화
- 기술 및 프로세스 격차 분석
- 성공적인 마이그레이션 지원
- 조직 변화 관리
- AWS 모범 사례(Best Practices) 제공

---

# AWS CAF 6가지 관점 요약

| 구분 | 관점 | 주요 내용 |
|------|------|-----------|
| **비즈니스 역량** | **Business** | 비즈니스 전략 및 투자 효과 |
| | **People** | 조직, 인력, 교육 및 변화 관리 |
| | **Governance** | 정책, 규정 준수, 위험 및 비용 관리 |
| **기술 역량** | **Platform** | AWS 인프라 및 마이그레이션 |
| | **Security** | 보안 정책, IAM, 암호화 |
| | **Operations** | 운영, 모니터링, 자동화, 장애 대응 |

---

# 핵심 정리

- **AWS Cloud Adoption Framework(AWS CAF)** 는 조직이 AWS 클라우드를 성공적으로 도입하고 마이그레이션할 수 있도록 지원하는 프레임워크이다.
- AWS CAF는 클라우드 도입을 **사람, 조직, 프로세스, 기술** 관점에서 체계적으로 관리하도록 돕는다.
- AWS CAF는 **Business, People, Governance, Platform, Security, Operations**의 **6가지 관점**으로 구성된다.
- **Business, People, Governance**는 **비즈니스 역량**, **Platform, Security, Operations**는 **기술 역량**에 중점을 둔다.
- 각 관점에서 **기술 및 프로세스 격차(Gap)** 를 분석하고, 이를 바탕으로 **AWS CAF 실행 계획(Action Plan)** 을 수립하여 성공적인 클라우드 마이그레이션과 조직 변화를 지원한다.
