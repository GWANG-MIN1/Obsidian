# AWS 마이그레이션(Migration)

## AWS 마이그레이션이란?

마이그레이션(Migration)은 기존 IT 환경의 애플리케이션과 데이터를 **AWS 클라우드로 이전하는 과정**을 의미한다.

마이그레이션 대상은 다음과 같다.

- 기존 온프레미스(On-Premises) 환경
- 다른 클라우드 서비스 제공업체(Cloud Provider)
- 하이브리드(Hybrid) 환경

AWS는 다양한 **도구(Tools), 솔루션(Solutions), 아키텍처(Architectures)** 를 제공하여 마이그레이션을 지원한다.

---

# AWS 마이그레이션의 3단계

AWS는 마이그레이션을 다음과 같은 **3단계 프로세스**로 수행할 것을 권장한다.

```
평가(Assess)

↓

동원(Mobilize)

↓

마이그레이션 및 현대화(Migration & Modernize)
```

---

# 1. 평가 단계 (Assess)

평가 단계에서는 현재 IT 환경을 분석하고 클라우드 도입 가능성을 평가한다.

### 주요 작업

- 현재 운영 환경 분석
- 조직의 클라우드 준비 상태 평가
- 비즈니스 목표 확인
- 마이그레이션 필요성 분석
- 애플리케이션 및 인프라 평가

### 목적

- 무엇을 마이그레이션할지 결정
- 클라우드 도입 효과 분석
- 마이그레이션 범위 정의

---

# 2. 동원 단계 (Mobilize)

동원 단계에서는 실제 마이그레이션을 위한 계획과 준비를 수행한다.

### 주요 작업

- 마이그레이션 계획 수립
- 조직 및 인력 준비
- 기술적 부족 사항 보완
- AWS 환경 구축
- 마이그레이션 전략 수립

### 목적

- 성공적인 마이그레이션 준비
- 비즈니스 목표에 맞는 전략 수립
- 위험 요소 최소화

---

# 3. 마이그레이션 및 현대화 단계 (Migration & Modernize)

실제 애플리케이션과 데이터를 AWS로 이전하는 단계이다.

단순히 이전하는 것뿐만 아니라, AWS 환경에 맞게 애플리케이션을 개선(현대화, Modernization)할 수 있다.

### 주요 작업

- 애플리케이션 마이그레이션
- 데이터 마이그레이션
- 시스템 검증 및 테스트
- 애플리케이션 현대화
- 운영 환경 전환

### 목적

- AWS 환경으로 안정적인 이전
- 성능 및 운영 효율성 향상
- 클라우드 서비스 적극 활용

---

# AWS 전문가 지원

AWS는 마이그레이션의 모든 단계에서 다양한 전문가와 서비스를 통해 고객을 지원한다.

대표적인 지원

- AWS Migration 전문가
- AWS Solutions Architect
- AWS Professional Services
- AWS Partner Network(APN)

이를 통해 고객은 보다 안전하고 효율적으로 클라우드로 이전할 수 있다.

---

# AWS 마이그레이션의 장점

- 기존 온프레미스 환경 이전 가능
- 다른 클라우드 환경에서도 이전 가능
- 단계별 체계적인 마이그레이션 지원
- AWS 전문가 지원
- 다양한 마이그레이션 도구 제공
- 애플리케이션 현대화 지원

---

# AWS 마이그레이션 프로세스 요약

| 단계 | 주요 내용 |
|------|-----------|
| **평가 (Assess)** | 현재 환경 분석, 클라우드 준비 상태 평가, 목표 및 마이그레이션 필요성 확인 |
| **동원 (Mobilize)** | 마이그레이션 계획 수립, 조직 및 기술 준비, 전략 수립 |
| **마이그레이션 및 현대화 (Migration & Modernize)** | 애플리케이션과 데이터를 AWS로 이전하고 검증 및 현대화 수행 |

---

# 핵심 정리

- AWS는 **온프레미스 환경**뿐만 아니라 **다른 클라우드 서비스 제공업체의 워크로드도 AWS로 마이그레이션**할 수 있도록 지원한다.
- AWS는 다양한 **도구, 솔루션, 아키텍처**를 제공하여 마이그레이션을 지원한다.
- 마이그레이션은 **평가(Assess) → 동원(Mobilize) → 마이그레이션 및 현대화(Migration & Modernize)** 의 3단계로 진행된다.
- **평가 단계**에서는 현재 환경과 클라우드 준비 상태를 분석하고, **동원 단계**에서는 마이그레이션 계획과 전략을 수립한다.
- **마이그레이션 및 현대화 단계**에서는 실제 이전과 검증을 수행하며, AWS 환경에 맞게 애플리케이션을 개선할 수 있다.
- AWS는 **Solutions Architect, Professional Services, APN 파트너** 등 다양한 전문가를 통해 마이그레이션 전 과정을 지원한다.
