## AWS 애플리케이션 및 컴퓨팅 서비스

### 1. AWS Elastic Beanstalk

> **애플리케이션을 EC2에 쉽게 배포하고 관리하는 서비스**

**특징**

- 애플리케이션 배포 자동화
- 간소화된 프로비저닝
- 구성(Configuration) 관리
- 애플리케이션 상태 모니터링 및 제어

**한 줄 요약**

> **"코드만 업로드하면 EC2 배포를 자동으로 관리하는 서비스"**

---

### 2. AWS Batch

> **대규모 배치(Batch) 작업을 자동으로 실행하는 서비스**

**특징**

- 대용량 데이터 처리
- 병렬 처리 지원
- 인프라 자동 관리
- 작업량에 따른 자동 스케일링

**한 줄 요약**

> **"대량의 작업을 효율적으로 처리하는 배치 컴퓨팅 서비스"**

---

### 3. Amazon Lightsail

> **웹사이트나 간단한 애플리케이션을 쉽게 구축하는 서비스**

**특징**

- 간편한 서버 생성
- 비용 효율적
- 관리형 인프라 제공
- 초보자도 쉽게 사용 가능

**한 줄 요약**

> **"간단한 웹사이트와 애플리케이션을 빠르게 구축하는 서비스"**

---

### 4. AWS Outposts Family

> **온프레미스와 AWS 클라우드를 연결하는 하이브리드 클라우드 서비스**

**특징**

- 하이브리드 클라우드 환경 구축
- AWS와 동일한 운영 경험 제공
- 짧은 지연 시간(Low Latency)
- 데이터를 온프레미스에서 처리 가능

**한 줄 요약**

> **"온프레미스에서도 AWS 환경을 그대로 사용할 수 있는 서비스"**



서비스 비교

| 서비스               | 용도             | 핵심 특징          |
| ----------------- | -------------- | -------------- |
| Elastic Beanstalk | 애플리케이션 배포      | EC2 배포 자동화     |
| AWS Batch         | 대규모 데이터 처리     | 병렬 처리, 자동 스케일링 |
| Lightsail         | 간단한 웹사이트, 앱 구축 | 저렴하고 사용이 쉬움    |
| Outposts Family   | 하이브리드 클라우드     | 온프레미스 + AWS 연동 |
