### AWS Lambda

> **서버를 직접 관리하지 않고, 이벤트가 발생하면 코드를 실행하는 서버리스 컴퓨팅 서비스**

#### 핵심 특징

- **서버 관리 불필요**
    - 서버 프로비저닝 및 운영을 AWS가 자동 수행
- **자동 스케일링**
    - 요청량에 따라 리소스를 자동으로 확장·축소
- **사용한 만큼만 과금(Pay-as-you-go)**
    - 코드가 실행된 시간과 횟수에 대해서만 비용 발생

---

### 활용 예시

#### 1. 소셜 미디어 이미지 처리

- 사용자가 이미지를 업로드하면 Lambda가 자동 실행
- 업로드 수에 따라 **자동으로 규모 조정**
- **이미지 처리 시간만큼만 요금 청구**

#### 2. 뉴스 애그리게이터의 개인화 콘텐츠 제공

- 사용자 요청이 있을 때만 코드 실행
- **트래픽 증가에 맞춰 자동 스케일링**
- 사용하지 않을 때는 비용이 발생하지 않아 **비용 절감**

#### 3. 온라인 게임 실시간 이벤트 처리

- 게임 내 수천 개의 이벤트를 실시간 처리
- **서버를 직접 관리할 필요 없음**
- 피크 시간에는 자동으로 확장하고, 한가한 시간에는 자동으로 축소하여 **사용량에 맞게 비용 최적화**

---

### 한 줄 요약

> **AWS Lambda는 이벤트가 발생할 때만 코드를 실행하며, 서버 관리·자동 스케일링·과금을 모두 AWS가 처리하는 대표적인 서버리스 서비스이다.**
