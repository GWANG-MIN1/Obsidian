### 서버리스(Serverless)

- **사용자는 서버(인프라)를 직접 관리하지 않음**
    - 서버를 보거나 접근할 필요가 없음
    - 인프라 운영은 클라우드 제공자가 담당
- **클라우드가 자동으로 처리**
    - 프로비저닝(서버 생성)
    - 스케일링(자동 확장/축소)
    - 가용성 및 장애 복구
    - 운영 및 유지보수
- **개발자는 애플리케이션(코드) 개발에만 집중**

---

### 예: AWS Lambda

- 코드를 업로드하면 **AWS가 서버 운영을 모두 자동 처리**
- 개발자가 신경 쓸 필요 없는 것
    - 서버 관리
    - 인프라 구성
    - 자동 스케일링
    - 가용성 및 장애 대응

➡️ **즉, 개발자는 코드만 작성하고, 나머지 운영은 AWS가 담당한다.**
