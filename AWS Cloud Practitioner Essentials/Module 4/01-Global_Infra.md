
| 기능                         | 역할                                                     |
| -------------------------- | ------------------------------------------------------ |
| **리전(Region)**             | **서비스를 배포할 위치를 선택** (AWS 전 세계 리전 중 선택)                 |
| **엣지 로케이션(Edge Location)** | **자주 요청되는 콘텐츠를 캐시에 저장**하여 사용자에게 더 빠르게 제공               |
| **AWS CloudFormation**     | **인프라를 코드(IaC)로 관리**하여 전 세계 어디서든 **일관된 환경으로 자동 배포** 가능 |
