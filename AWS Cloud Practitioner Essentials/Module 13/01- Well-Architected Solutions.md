# AWS Well-Architected Framework

## AWS Well-Architected Framework란?

AWS는 수백 개의 클라우드 서비스를 제공하며, 이를 조합하면 거의 모든 형태의 아키텍처를 구축할 수 있다.

하지만 다양한 서비스를 사용할 수 있다고 해서 **항상 좋은 아키텍처가 되는 것은 아니다.**

AWS는 설계한 아키텍처가 **AWS의 모범 사례(Best Practices)** 를 따르는지 평가할 수 있도록 **AWS Well-Architected Framework**를 제공한다.

쉽게 말하면,

> **구축한 AWS 아키텍처가 잘 설계되었는지 점검하고 개선할 수 있도록 도와주는 설계 가이드라인**이다.

---

# 왜 필요한가?

클라우드에서는 다양한 아키텍처를 자유롭게 구축할 수 있지만 다음과 같은 문제가 발생할 수 있다.

- 비용이 과도하게 발생
- 보안 취약점 존재
- 장애 발생 시 복구 어려움
- 성능 부족
- 운영이 복잡함

AWS Well-Architected Framework는 이러한 문제를 미리 발견하고 개선하도록 지원한다.

---

# AWS Well-Architected Framework의 목적

- 아키텍처 품질 평가
- AWS 모범 사례(Best Practices) 적용
- 설계상의 위험 요소 식별
- 비용 최적화
- 안정성과 보안 향상
- 지속적인 아키텍처 개선

---

# 평가 방법

AWS Well-Architected Framework는 구축한 시스템을 여러 관점에서 검토하여

- 현재 설계가 적절한지
- 개선이 필요한 부분은 무엇인지
- AWS 권장 사항을 얼마나 준수하는지

를 평가한다.

이를 통해 아키텍처를 지속적으로 개선할 수 있다.

---

# Well-Architected Review

AWS에서는 Well-Architected Framework를 기반으로 **Well-Architected Review(WAR)** 를 수행할 수 있다.

검토를 통해

- 위험 요소(High Risk Issues) 식별
- 개선 권장 사항 제공
- AWS 모범 사례 적용 여부 확인

등을 수행한다.

---

# AWS Well-Architected Framework의 6가지 핵심 요소(Pillars)

AWS Well-Architected Framework는 다음 **6개의 핵심 요소(Pillars)** 를 기준으로 아키텍처를 평가한다.

| 핵심 요소(Pillar) | 목적 |
|-------------------|------|
| **Operational Excellence** | 운영 효율성 |
| **Security** | 보안 |
| **Reliability** | 안정성 및 복구 |
| **Performance Efficiency** | 성능 효율성 |
| **Cost Optimization** | 비용 최적화 |
| **Sustainability** | 지속 가능성 |

> ※ 각 Pillar의 세부 내용은 별도로 학습하며, Cloud Practitioner 시험에서도 매우 중요한 개념이다.

---

# AWS Well-Architected Framework의 장점

- AWS 모범 사례 적용
- 설계 품질 향상
- 위험 요소 사전 발견
- 보안 강화
- 비용 절감
- 성능 향상
- 안정적인 운영 지원

---

# 핵심 정리

- AWS는 수백 개의 서비스를 제공하며 이를 조합하여 다양한 아키텍처를 구축할 수 있다.
- **AWS Well-Architected Framework**는 구축한 아키텍처가 **AWS의 모범 사례(Best Practices)** 를 따르는지 평가하는 프레임워크이다.
- Well-Architected Framework를 활용하면 **설계 품질을 평가하고 위험 요소를 식별하며, 비용·보안·성능·안정성을 지속적으로 개선**할 수 있다.
- AWS는 **Well-Architected Review(WAR)** 를 통해 현재 아키텍처를 검토하고 개선 권장 사항을 제공한다.
- Well-Architected Framework는 **Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability**의 **6가지 핵심 요소(Pillars)** 를 기준으로 아키텍처를 평가한다.
